.# 🏠 GuestNest

> A full-stack property rental platform built with the MERN stack.

![Homepage Screenshot](./screenshots/homepage.png)


## 🔍 Overview

**GuestNest** is a complete property booking platform that allows users to list, discover, and book accommodations worldwide. 

### Key Highlights:
- 🔐 Secure user authentication & authorization
- 🏡 Property listing with image uploads
- 🔍 Advanced search & filtering
- 💬 Real-time review system
- 💳 Payment integration ready
- 📱 Fully responsive design

## ✨ Features

### User Features
- **Authentication**: Sign up, login, and logout with JWT-based authentication
- **Property Management**: Create, edit, delete property listings
- **Search & Filter**: Find properties by location, price range, and amenities
- **Booking System**: Book properties with date selection
- **Reviews & Ratings**: Leave reviews and ratings for properties
- **User Dashboard**: View booking history and manage listings

### Property Owner Features
- **List Properties**: Upload property images and details
- **Availability Management**: Set property availability dates
- **Booking Management**: View and manage incoming booking requests

### Technical Features
- RESTful API architecture
- MongoDB database with mongoose ODM
- Cloudinary integration for image storage
- Responsive UI with React and Tailwind CSS
- Protected routes and API endpoints

## 🛠️ Tech Stack

```

| Category | Technology |
|----------|------------|
| **Frontend** | React.js, React Router, Tailwind CSS, Axios |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB, Mongoose ODM |
| **Authentication** | JSON Web Tokens (JWT), bcryptjs |
| **File Upload** | Multer, Cloudinary |
| **Payment** | Stripe/Razorpay (optional) |
| **State Management** | React Context API / Redux |

```
